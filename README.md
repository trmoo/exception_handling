# 🥤 부숴봐! 자판기 — 파이썬 예외 처리

> © 2026 티쳐무 · 모든 권리 보유 — 학교 수업 목적으로만 이용해 주세요. ([LICENSE](LICENSE))

귀여운 자판기 뒤에서 파이썬 코드가 돌고 있습니다.
**1라운드**에서는 이상한 값을 넣어 자판기를 고장 내고, 그때 난 예외(`ValueError`·`IndexError`…)를
**예외 도감** 카드로 모읍니다. **2라운드**에서는 `try`·`except` 로 방어막을 직접 짜서,
같은 공격을 다시 넣었을 때 자판기가 「숫자만 넣어주세요 😊」 라고 침착하게 대답하게 만듭니다.
반 전체의 발견과 방어는 **교실 TV 리더보드**에 실시간으로 뜹니다.

- **주소: https://exception-handling.enssam21.workers.dev** (Cloudflare Workers)
- 대상: 고등학교 「프로그래밍」(파이썬) — 예외 처리 단원, **2차시**
- 파이썬 설치·인터넷 없이 브라우저에서 진짜로 실행됩니다 (리더보드만 인터넷 필요)
- 이름·학번을 받지 않습니다

## 쓰는 법 (학생)

1. **🎰 부숴봐!** — 돈·상품 번호·쿠폰·사람 수를 바꿔 넣고 [▶ 넣기]. 자판기를 고장 내면 카드가 모입니다.
   숨은 함정 카드 2장은 「고장은 안 났는데 이상한」 경우입니다. 막히면 💡 힌트.
2. **📖 예외 도감** — 카드를 눌러 언제 나는 예외인지, Traceback 을 어떻게 읽는지 봅니다.
3. **🛡️ 방어막** — 미션 1~5 의 빈칸을 채우고 [🛡️ 채점하기]. 1라운드의 공격이 그대로 다시 들어와
   「1라운드 💥 → 지금 🛡️」 로 나란히 보입니다. 미션 6 은 보스전(공격 13가지 + 정상 손님 4명, 별 셋).
4. **🏆 우리 반** — 선생님이 알려 준 방 코드를 넣고 모둠을 고르면 내 기록이 모둠 점수로 모입니다.
5. **📘 정리** — try 문이 도는 차례를 값을 바꿔 가며 확인하고, 확인 문제 7개를 풉니다.

## 쓰는 법 (선생님)

| | |
|---|---|
| 주소 | 배포한 주소, 또는 `dist/index.html` 을 더블클릭 |
| TV 화면 | 🏆 우리 반 → 👩‍🏫 선생님용 → [🎲 새 방 만들기] → [📺 TV 화면 열기] |
| 학생 입장 | TV 에 뜬 주소로 들어오거나, 방 코드 4글자를 🏆 탭에 입력 |
| 라운드 바꾸기 | TV 화면 아래 [💥 1라운드] [🛡️ 2라운드] — 순위 기준이 「발견」 ↔ 「방어」 로 바뀜 |
| 리허설 | TV 화면의 [🎭 연습용 가짜 모둠] — 화면에만 가짜 점수가 움직이고 서버에는 쓰지 않음 |
| 수업 흐름 | 📘 정리 탭 맨 아래 「선생님용 — 2차시 수업 흐름」 |
| 기록 지우기 | 📘 정리 탭 맨 아래 [🧹 내 기록 지우기] (공용 컴퓨터) |

## 실시간 리더보드 설정 (처음 한 번, 10분)

리더보드는 **Firebase 실시간 데이터베이스**(Google, 무료 요금제로 충분)에 모둠 점수를 모읍니다.
설정하지 않아도 리더보드를 뺀 모든 활동은 됩니다.

1. <https://console.firebase.google.com> 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다)
2. 왼쪽 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: 싱가포르(`asia-southeast1`) 권장
   - 보안 규칙: **잠금 모드로 시작**
3. **규칙** 탭에 [`docs/firebase-rules.json`](docs/firebase-rules.json) 내용을 통째로 붙여 넣고 **게시**
4. **데이터** 탭 위쪽의 주소를 복사합니다 — `https://(프로젝트)-default-rtdb.asia-southeast1.firebasedatabase.app`
5. 앱의 **🏆 우리 반 → 👩‍🏫 선생님용** 에 주소를 붙여 넣고 **[연결 시험 · 저장]** → 🟢 가 뜨면 끝
6. **[🎲 새 방 만들기]** — 방 코드와 **학생 주소**가 나옵니다. 학생 주소에는 서버 주소가 함께 들어 있어서,
   학생은 그 주소로 열기만 하면 자동으로 연결됩니다.

보안 규칙이 하는 일 — 방 코드 꼴(대문자·숫자 4~6자)의 방 아래에서 **모둠 번호(1~12)·카드 이름·
미션 수(0~6)·보스전 점수(0~13)** 만 쓸 수 있게 막습니다. 다른 글자는 한 칸도 들어가지 않습니다.
로그인이 없으므로 방 코드를 아는 사람은 누구나 쓰고 지울 수 있습니다 — 수업이 끝나면 TV 화면의
[🧹 방 비우기] 로 지워 주세요.

- 무료 요금제는 **동시 접속 100개**까지입니다. 한 반(30명 + TV)은 넉넉합니다.
- API 키나 SDK 는 쓰지 않습니다. 앱은 주소로 REST 요청과 EventSource 만 보냅니다(바깥 라이브러리 0개).
- 인터넷이 끊기면 상단 칩이 🟠 로 바뀌고, 학생 활동은 그대로 계속됩니다.

## 배포 (Cloudflare Workers)

GitHub `main` 에 올리면 Cloudflare 가 스스로 `npm run build` → `npx wrangler deploy` 를 돌려
`dist/` 를 정적 파일로 올린다. 설정은 [`wrangler.jsonc`](wrangler.jsonc) 하나(서버 코드 없음).
GitHub Actions 의 `check` 워크플로는 시험·소스 검사·빌드 점검만 한다(배포하지 않는다).

## 개발

```bash
npm install
npm start            # 개발 서버 (index.html)
npm test             # 시험 491가지 — 진짜 파이썬 대조 157사례 포함
npm run check:syntax # 소스 전수 검사 (문법·저작권·화면 수명·바깥 주소)
npm run build        # dist/index.html 한 파일 (약 170KB, 더블클릭 실행)
```

- `python tools/golden.py` — 해석기를 견줄 기준을 진짜 파이썬으로 다시 만든다 (`test/golden.json`)
- `node tools/mock-firebase.mjs 9010` — 가짜 Firebase. 선생님용 서버 주소에 `http://localhost:9010`
